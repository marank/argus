# Reporting a problem

If a device does not work, is damaged or lost, report it to IT directly in Argus.

## Creating a report

1. Open **Self-service → My devices** and choose the device.
2. Click **Report a problem**.
3. Under **What happened?** choose the kind: **Not working**, **Damaged**, **Lost or stolen** or **Other**.
4. Describe the problem: what does not work, since when, and what you have already tried.
5. **Send to IT**.

You can only report problems for devices handed out to you. For anything else, contact IT directly.

## Following a report

Under **Self-service → My reports** you see your reports, split into **Open** and **Resolved**, with the latest message.

In a report, you and IT can write messages at any time, even after it is resolved. Press **Ctrl + Enter** to send a message.

If the problem has gone away, mark the report yourself with **Mark as resolved**. Any message you have typed is sent along with it.

| Status | Meaning |
| --- | --- |
| **Open** | IT has not picked up the report yet. |
| **In progress** | IT is working on it. |
| **Resolved** | The problem is fixed. |

::: info Good to know
- When IT writes to you or changes the status, the number next to **My reports** pulses until you open the report.
- The device page shows open reports and those resolved in the last 14 days.
- When you return a device, your reports about it stay visible and are marked **returned**.
:::
