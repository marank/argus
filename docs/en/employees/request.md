# Requesting

Under **Self-service → New request** you request devices, accessories, consumables and software from IT.

## Step 1: Details

| Field | Meaning |
| --- | --- |
| **Purpose** | What you need the devices for, e.g. "Training" or "new employee". Required. |
| **Duration** | **Temporary**: borrow for a period. **Permanent**: keep as a work tool. |
| **Period** | For temporary requests: from when until when. The standard loan period is suggested. |
| **Needed from** | For permanent requests: from when. |
| **Preferred pickup day** | Your preferred day for the pickup. IT sets the exact appointment. |

The preferred day automatically follows the first day of the period until you change it. It may be earlier, but not in the past and not after the day from which you need the devices.

## Step 2: Selection

Choose a category or search directly, e.g. for "Headset". Depending on the category you have these options:

- **Any model**, e.g. "Headset · any model": IT picks a suitable device.
- **A specific model**: you decide the model.
- **Something else from {category}**: you describe what you need. IT reviews the request.

IT decides which options a category offers. For some categories IT always chooses the model, for others (e.g. toner) you have to choose a specific model.

Use **+** and **−** to set the quantity. You can add a **Note** to each item.

### For your devices

This tile shows consumables and accessories that fit your own devices, e.g. the right ink cartridge for your printer.

### Accessories

Matching accessories appear below a model, e.g. a docking station for the notebook.

### Not in the catalog?

If the search finds nothing, describe what you need under **Item not in the catalog?**. Such lines appear in the cart as **Custom request · IT will check**.

### Software

You request software just like devices, in the software categories. IT then assigns you a license. It appears under [My software](./overview#my-software).

## Step 3: Review and submit

The **Cart** shows all lines. Under **Message** you can tell IT anything else. **Submit request** sends the request.

You then see the request with its number. What happens next:

- **With approval:** If the request contains something your department has to approve, it goes to the approvers first. Status: **Awaiting approval**.
- **Without approval:** The request goes straight to IT. Status: **Submitted**.

You are notified by email and in Argus as soon as something happens.

::: info Good to know
- A single line that needs approval is enough, and the whole request needs approval.
- If you are an approver of your department yourself, your own request counts as approved.
- If you are exempt from approvals, every request goes straight to IT.
- If IT has set a maximum loan period, you cannot choose a longer period.
- Only IT staff can see how many devices are available. Request what you need; IT will get in touch if something is not available.
:::

## Requesting again

Completed, rejected or cancelled requests offer **Request again**. The form is then filled with the previous details; dates in the past are set to today. Submitting creates a new request that refers to the old one.

## Cancelling a request

As long as you are still in the form, **Cancel request** discards all details. You can cancel a request you have already submitted, see [My requests](./overview#cancelling).
