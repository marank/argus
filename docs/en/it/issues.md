# Problem reports

Under **IT operations → Problem reports** IT handles problems that employees report about their devices. How employees report problems is described under [Reporting a problem](../employees/report-issue).

## The list

By default, the list shows open problem reports and those in progress. At the top you choose:

| View | Content |
| --- | --- |
| **All** | All problem reports |
| **Assigned to me** | Problem reports you are working on |
| **My teams** | Problem reports of your teams |
| **Unassigned** | Problem reports without anyone working on them |

## Responsibility

A new problem report goes to the team of the device model or its category, otherwise to the default team. The team receives the notification **New problem report**; without a team, all of IT does.

Under **Responsible** you change the team and the person working on it and apply both with **Save**; **Assign to me** saves right away. If someone else takes over, that person receives the notification **Assigned to me**. The employee does not see who is responsible.

## Handling

1. **Start working on it** shows the employee that someone is taking care of it.
2. Write messages: questions, hints, the result. The employee receives every message as a notification.
3. **Mark as resolved** once the problem is fixed. A message you have typed is sent along.

If needed, you open a resolved problem report again with **Reopen**. The employee can also mark a problem report as resolved; if they write a message or close it, IT receives the notification **Reply on problem report**.

The detail page also shows the device, the employee's contact details and other problem reports about the same device.

## What a problem report does not do

A problem report does not change the device status. For a defect, set the device to **In repair** yourself, for a loss to **Lost**, or [replace](./devices#replacing-a-device) it.

The report and its resolution appear as **Problem reported** and **Problem resolved** in the device's service log.

::: info Good to know
Only employees create problem reports themselves, and only for devices handed out to them. IT does not create problem reports; record your own findings with **Record service** in the service log.
:::
