# Status overview

All statuses in Argus at a glance.

## Requests

| Status | Meaning | Next step |
| --- | --- | --- |
| **Awaiting approval** | Waiting for the department | The approver decides |
| **Submitted** | With IT | IT confirms or rejects |
| **Confirmed** | IT has committed and is preparing | IT assigns devices, finishes the preparation |
| **Ready for handover** | Devices are ready | Pickup or hand-out |
| **Handed out** | Temporary loan in progress | Return |
| **Completed** | Handed out permanently or everything returned | – |
| **Rejected** | Rejected by IT or the department | Request again if needed |
| **Cancelled** | Withdrawn | Request again if needed |

**Approval:** Pending, Approved, Not approved

**Duration:** Temporary, Permanent

## Handover

| Type | Process |
| --- | --- |
| **Pickup with signature** | At the pickup terminal |
| **Simple pickup** | Without a signature; IT records the recipient |
| **Delivered by IT** | IT brings the devices |

The record shows how the handover took place: **Signed at terminal**, **Delivered by IT** or **Handed out by IT**.

## Devices

| Status | Meaning |
| --- | --- |
| **In stock** | Available |
| **Reserved** | Assigned to a request |
| **In use** | With an employee |
| **In repair** | Defective or being serviced |
| **Lost** | Cannot be found |
| **Retired** | Out of service |

**Condition:** New, Good, Worn, Defective

## Problem reports

| Status | Meaning |
| --- | --- |
| **Open** | Not yet taken on |
| **In progress** | IT is taking care of it |
| **Resolved** | Done |

**Type:** Not working, Damaged, Lost or stolen, Other

## Orders

| Status | Meaning |
| --- | --- |
| **To order** | Draft |
| **Ordered** | Ordered from the supplier |
| **Partially received** | Part has arrived |
| **Received** | Arrived in full |
| **Cancelled** | Cancelled |

## Consumable movements

**Goods receipt**, **Issue**, **Adjustment**, **Used for repair**

## Service log entries

| Automatic | Manual |
| --- | --- |
| Created, Status changed, Handed out, Returned, Device replaced, Problem reported, Problem resolved | Component replaced, Repair, Maintenance, Inspection, Note |
