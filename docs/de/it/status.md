# Statusübersicht

Alle Status in Argus auf einen Blick.

## Anforderungen

| Status | Bedeutung | Nächster Schritt |
| --- | --- | --- |
| **In Genehmigung** | Wartet auf die Abteilung | Genehmiger entscheidet |
| **Eingereicht** | Liegt bei der IT | IT bestätigt oder lehnt ab |
| **Bestätigt** | IT hat zugesagt, bereitet vor | IT weist Geräte zu, schließt die Vorbereitung ab |
| **Bereit zur Übergabe** | Geräte liegen bereit | Abholung oder Ausgabe |
| **Ausgegeben** | Befristete Ausleihe läuft | Rückgabe |
| **Abgeschlossen** | Dauerhaft ausgegeben oder alles zurück | – |
| **Abgelehnt** | Von der IT oder der Abteilung abgelehnt | Ggf. erneut anfordern |
| **Storniert** | Zurückgezogen | Ggf. erneut anfordern |

**Genehmigung:** Ausstehend, Genehmigt, Nicht genehmigt

**Dauer:** Befristet, Dauerhaft

## Übergabe

| Art | Ablauf |
| --- | --- |
| **Abholung mit Unterschrift** | Am Abholterminal |
| **Einfache Abholung** | Ohne Unterschrift; die IT erfasst den Empfänger |
| **Lieferung durch IT** | Die IT bringt die Geräte |

Im Protokoll steht, wie übergeben wurde: **Am Terminal unterschrieben**, **Durch IT geliefert** oder **Durch IT ausgegeben**.

## Geräte

| Status | Bedeutung |
| --- | --- |
| **Im Lager** | Verfügbar |
| **Reserviert** | Einer Anforderung zugewiesen |
| **In Benutzung** | Bei einem Mitarbeiter |
| **In Reparatur** | Defekt oder beim Service |
| **Verloren** | Nicht auffindbar |
| **Ausgemustert** | Außer Betrieb |

**Zustand:** Neu, Gut, Gebraucht, Defekt

## Meldungen

| Status | Bedeutung |
| --- | --- |
| **Offen** | Noch nicht aufgenommen |
| **In Bearbeitung** | Die IT kümmert sich |
| **Gelöst** | Erledigt |

**Art:** Funktioniert nicht, Beschädigt, Verloren oder gestohlen, Sonstiges

## Bestellungen

| Status | Bedeutung |
| --- | --- |
| **Zu bestellen** | Entwurf |
| **Bestellt** | Beim Lieferanten bestellt |
| **Teilweise geliefert** | Teil eingegangen |
| **Geliefert** | Vollständig eingegangen |
| **Storniert** | Abgebrochen |

## Verbrauchsmaterial-Bewegungen

**Wareneingang**, **Ausgabe**, **Korrektur**, **Für Reparatur verbraucht**

## Servicebuch-Einträge

| Automatisch | Von Hand |
| --- | --- |
| Angelegt, Status geändert, Ausgegeben, Zurückgegeben, Gerät ersetzt, Problem gemeldet, Problem behoben | Komponente getauscht, Reparatur, Wartung, Prüfung, Notiz |
