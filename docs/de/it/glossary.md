# Begriffe

Die wichtigsten Begriffe in Argus, nach Themen geordnet.

## Rund um Anforderungen

| Begriff | Bedeutung |
| --- | --- |
| **Anforderung** | Der Wunsch einer Person nach Geräten, Software oder Verbrauchsmaterial. Eine Anforderung kann befristet (Ausleihe) oder dauerhaft sein. Mitarbeitende stellen sie im Self-Service, die IT kann sie auch im Namen anderer anlegen. |
| **Position** | Eine Zeile einer Anforderung, z. B. „1 × Headset, beliebiges Modell“ oder „2 × Tonerkartusche“. |
| **Genehmigung** | Die Freigabe durch die eigene Abteilung. Nur für Kategorien nötig, die eine Genehmigung verlangen. |
| **Bestätigung** | Die Annahme der Anforderung durch die IT. Erst danach plant die IT Abholung und Geräte. |
| **Zuweisung** | Ein konkretes Gerät, das die IT für eine Position vorsieht. Das Gerät ist dann **reserviert**. |
| **Übergabe (Ausgabe)** | Die Ausgabe der Geräte an die Person. Sie wird protokolliert, wahlweise mit Unterschrift am Abholterminal. |
| **Direktausgabe** | Die IT stellt bestimmte Geräte aus dem Lager für eine Person bereit, ohne Anforderung und ohne Genehmigung. |
| **Sonderwunsch** | Eine Position, die nicht im Katalog steht und frei beschrieben wird. Die IT ordnet ihr ein Modell zu. |
| **Rückgabe** | Die Rücknahme ausgegebener Geräte durch die IT. |

## Rund um das Inventar

| Begriff | Bedeutung |
| --- | --- |
| **Gerät** | Ein einzeln erfasstes Stück Hardware mit Inventarnummer, z. B. Laptop, Smartphone, Headset oder MDE. |
| **Inventarnummer** | Die feste Kennung eines Geräts. Sie bleibt ein Leben lang beim Gerät. |
| **Gerätename** | Der Name eines Geräts an seinem Einsatzort, z. B. der Hostname eines PCs oder der Name eines MDE im MDM. Der Name gehört zum Einsatzort: Wird ein Gerät ersetzt, übernimmt das Ersatzgerät seinen Namen. |
| **Modell** | Ein Gerätetyp eines Herstellers, z. B. „Jabra Evolve2 65“. Jedes Gerät gehört zu einem Modell, jedes Modell zu einer Kategorie. |
| **Kategorie** | Eine Gruppe von Modellen, z. B. „Headsets“ oder „Notebooks“. Kategorien legen fest, ob Geräte einzeln, als Menge oder als Lizenz verwaltet werden und ob eine Genehmigung nötig ist. |
| **Verbrauchsmaterial** | Material, das nach Menge pro Lagerort geführt wird, z. B. Tintenpatronen oder Kabel. |
| **Lizenz** | Eine Softwarelizenz mit einer Anzahl an Plätzen und einer Laufzeit. Sie wird Mitarbeitenden oder Geräten zugewiesen. |
| **Servicebuch** | Der Lebenslauf eines Geräts: Ausgaben, Rückgaben, Reparaturen, Wartungen, Prüfungen und Notizen. |
| **Meldung** | Ein gemeldetes Problem mit einem Gerät, z. B. ein Defekt, ein Schaden oder ein Verlust. |

## Rund um die Beschaffung

| Begriff | Bedeutung |
| --- | --- |
| **Bedarf** | Was fehlt, um offene Anforderungen zu erfüllen oder den Mindestbestand an Verbrauchsmaterial zu halten. |
| **Bestellung** | Eine Bestellung bei einem Lieferanten. Beim Wareneingang entstehen daraus Geräte oder Lagerbestand. |

## Übergreifend

| Begriff | Bedeutung |
| --- | --- |
| **Nummernserie** | Ein Muster für fortlaufende Nummern. Argus vergibt daraus Inventarnummern, Gerätenamen, Anforderungsnummern und Bestellnummern. Siehe [Nummernserien](./administration/master-data#nummernserien). |
| **Team** | Eine Gruppe von IT-Mitarbeitenden, der Anforderungen und Meldungen automatisch zugeordnet werden, z. B. nach Kategorie. |

## Personen und Zugänge

| Begriff | Bedeutung |
| --- | --- |
| **Mitarbeitende** | Alle, die Argus im Self-Service nutzen: anfordern, eigene Geräte einsehen, Probleme melden. |
| **IT-Mitarbeitende** | Benutzer mit Rollen, die Zugriff auf Bereiche des IT-Betriebs geben. |
| **Administratoren** | Benutzer mit vollen Rechten, inklusive Einstellungen und Rollenverwaltung. |
| **Genehmiger** | Mitarbeitende, die Anforderungen ihrer Abteilung genehmigen. |
| **Vertretung** | Jemand, der in einem Zeitraum für einen Genehmiger entscheidet. Genehmiger tragen ihre Vertretung selbst ein. |
| **Terminal-Konto** | Ein Zugang für einen gemeinsam genutzten Touch-PC, an dem Mitarbeitende vorbereitete Geräte abholen und unterschreiben. |
