# Konto und Einstellungen

Alle persönlichen Einstellungen finden Sie im Benutzermenü oben rechts.

## Anmelden

Melden Sie sich mit Benutzername und Passwort an. Ist die Anmeldung über das Firmenverzeichnis eingerichtet, sind das Ihre Windows-Zugangsdaten.

Eine Anmeldung gilt eine bestimmte Zeit, meist einen Arbeitstag. Danach melden Sie sich neu an.

Nach zu vielen falschen Passwörtern ist die Anmeldung für 15 Minuten gesperrt. Wenden Sie sich an die IT, wenn es schneller gehen muss.

## Passwort

Unter **Anmeldung & Sicherheit**:

- **Mit Firmenverzeichnis:** Ihr Passwort ändern Sie dort, nicht in Argus.
- **Mit eigenem Argus-Konto:** **Passwort ändern**, aktuelles Passwort eingeben, dann das neue zweimal. Andere Anmeldungen, z. B. auf einem zweiten Rechner, werden danach abgemeldet.

Ein neues Passwort hat mindestens 8 Zeichen, besteht nicht nur aus Ziffern und ist kein gängiges Passwort.

Steht dort, dass die IT Ihr Passwort festlegt, wenden Sie sich für ein neues Passwort an die IT.

## Zwei-Faktor-Anmeldung

Unter **Anmeldung & Sicherheit** können Sie einen zweiten Anmeldeschritt einrichten. Bei der Anmeldung geben Sie dann zusätzlich einen 6-stelligen Code ein.

| Methode | Ablauf |
| --- | --- |
| **Authenticator-App** (empfohlen) | QR-Code mit einer App wie Microsoft Authenticator scannen. Die App zeigt den Code. |
| **Code per E-Mail** | Argus schickt bei jeder Anmeldung einen Code an Ihre E-Mail-Adresse. |

Beim Einrichten zeigt Argus einmalig zehn **Backup-Codes**. Bewahren Sie sie sicher auf: Jeder Code ersetzt einmal den Code aus App oder E-Mail, z. B. wenn das Telefon fehlt.

Haben Sie Telefon und Backup-Codes verloren, setzt die IT Ihre Zwei-Faktor-Anmeldung zurück, nachdem sie Ihre Identität geprüft hat.

## Benachrichtigungen

Argus benachrichtigt Sie per E-Mail und über die Glocke oben rechts, z. B. wenn Ihre Anforderung bestätigt wurde, die Geräte bereit sind oder eine Rückgabe ansteht.

Unter **Benachrichtigungen** legen Sie für jede Art fest, ob Sie sie per E-Mail, in der App oder gar nicht erhalten. Was die IT grundsätzlich abgeschaltet hat, erscheint dort nicht.

Ihre E-Mail-Adresse pflegt die IT. Stimmt sie nicht, wenden Sie sich an die IT.

## Sprache und Darstellung

- **Sprache:** Deutsch oder English. Auch E-Mails kommen in dieser Sprache.
- **Darstellung:** System, Hell, Solarized, Dunkel oder Retro. **System** folgt der Einstellung Ihres Geräts.

Beides gilt auf allen Geräten, an denen Sie sich anmelden.
