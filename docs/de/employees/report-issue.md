# Probleme melden

Funktioniert ein Gerät nicht, ist es beschädigt oder verloren, melden Sie das der IT direkt in Argus.

## Meldung erstellen

1. **Self-Service → Meine Geräte** öffnen und das Gerät wählen.
2. **Problem melden** klicken.
3. Unter **Was ist passiert?** die Art wählen: **Funktioniert nicht**, **Beschädigt**, **Verloren oder gestohlen** oder **Sonstiges**.
4. Das Problem beschreiben: was nicht funktioniert, seit wann und was Sie schon versucht haben.
5. **An die IT senden**.

Probleme melden Sie nur für Geräte, die Ihnen ausgegeben sind. Für andere Anliegen wenden Sie sich direkt an die IT.

## Meldung verfolgen

Unter **Self-Service → Meine Meldungen** sehen Sie Ihre Meldungen, getrennt nach **Offen** und **Gelöst**, mit der letzten Nachricht.

In einer Meldung können Sie und die IT jederzeit Nachrichten schreiben, auch nach der Lösung. Mit **Strg + Enter** senden Sie eine Nachricht.

Hat sich das Problem erledigt, markieren Sie die Meldung selbst mit **Als gelöst markieren**. Eine eingegebene Nachricht wird dabei mitgesendet.

| Status | Bedeutung |
| --- | --- |
| **Offen** | Die IT hat die Meldung noch nicht aufgenommen. |
| **In Bearbeitung** | Die IT kümmert sich darum. |
| **Gelöst** | Das Problem ist behoben. |

::: info Gut zu wissen
- Schreibt Ihnen die IT oder ändert sie den Status, pulsiert die Zahl neben **Meine Meldungen**, bis Sie die Meldung öffnen.
- Auf der Geräteseite sehen Sie offene Meldungen und solche, die in den letzten 14 Tagen gelöst wurden.
- Geben Sie ein Gerät zurück, bleiben Ihre Meldungen dazu sichtbar und sind als **zurückgegeben** markiert.
:::
