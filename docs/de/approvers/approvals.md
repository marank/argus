# Genehmigungen

Für manche Kategorien, z. B. teure Geräte, muss die Abteilung eine Anforderung genehmigen, bevor die IT sie bearbeitet. Diese Seite richtet sich an Genehmiger.

Alles Weitere zu Argus, z. B. wie Sie selbst etwas anfordern, steht im Bereich [Argus für Mitarbeitende](../employees/).

## Wer genehmigt

Die IT hinterlegt an jeder Abteilung, wer genehmigt. Hat eine Abteilung keine eigenen Genehmiger, entscheiden die Genehmiger der übergeordneten Abteilung. Bei Abwesenheit entscheidet zusätzlich die [Vertretung](./delegation), die ein Genehmiger eingetragen hat.

Als Genehmiger sehen Sie im Self-Service den Menüeintrag **Genehmigungen**. Die Zahl daneben zeigt, wie viele Anforderungen auf Sie warten. Zusätzlich erhalten Sie eine Benachrichtigung **Genehmigung erforderlich**.

## Genehmigen oder ablehnen

1. **Self-Service → Genehmigungen** öffnen. Die älteste Anforderung steht oben.
2. Anforderung öffnen und prüfen: wer, was, wofür und für welchen Zeitraum.
3. Entscheiden:
   - **Genehmigen**, optional mit Kommentar. Die Anforderung geht an die IT.
   - **Ablehnen** mit einer Begründung für den Mitarbeiter. Die Begründung ist Pflicht.

Nach der Entscheidung verschwindet die Anforderung aus Ihrer Liste. Es genügt die Entscheidung eines Genehmigers. Der Mitarbeiter erfährt das Ergebnis per Benachrichtigung.

Bei einer erneuten Anforderung zeigt Argus, auf welche frühere Anforderung sie folgt und warum diese abgelehnt wurde.

## Wann keine Genehmigung nötig ist

Eine Anforderung geht direkt an die IT, wenn

- keine Position aus einer genehmigungspflichtigen Kategorie stammt,
- der Mitarbeiter von Genehmigungen befreit ist,
- die IT die Anforderung im Namen des Mitarbeiters erfasst hat oder
- weder die Abteilung noch eine übergeordnete Abteilung Genehmiger hat.

Fordern Sie als Genehmiger selbst etwas an, gilt Ihre Anforderung als genehmigt.

## Fragen

### Eine Entscheidung war falsch.

Eine Entscheidung lässt sich nicht zurücknehmen. Bei einer versehentlichen Genehmigung wenden Sie sich an die IT, sie kann die Anforderung ablehnen. Nach einer versehentlichen Ablehnung fordert der Mitarbeiter mit **Erneut anfordern** neu an.

### Ich bin abwesend.

Tragen Sie selbst eine Vertretung für den Zeitraum ein, siehe [Vertretung bei Abwesenheit](./delegation).

### Ich bekomme keine Benachrichtigungen.

Prüfen Sie im Benutzermenü unter **Benachrichtigungen**, ob **Genehmigung erforderlich** eingeschaltet ist. Offene Genehmigungen sehen Sie in jedem Fall an der Zahl neben **Genehmigungen**.
