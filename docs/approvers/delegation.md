# Vertretung bei Abwesenheit

Sind Sie im Urlaub oder krank, tragen Sie selbst eine Vertretung ein. Die Vertretung entscheidet im eingetragenen Zeitraum über die Anforderungen Ihrer Abteilung, genau wie Sie.

Alles dazu finden Sie unter **Self-Service → Vertretung**.

## Die Seite im Überblick

| Bereich | Inhalt |
| --- | --- |
| **Status** | Ob Sie gerade vertreten werden, durch wen und bis wann, oder welche Vertretung als Nächstes geplant ist. Darunter die Abteilungen, für die Sie genehmigen. |
| **Ich vertrete** | Nur wenn Sie selbst jemanden vertreten: wen und in welchem Zeitraum. |
| **Meine Vertretungen** | Laufende und geplante Vertretungen mit Status **Läuft** oder **Geplant**. |
| **Vergangene Vertretungen** | Die letzten beendeten Vertretungen, eingeklappt. |

## Vertretung eintragen

1. **Vertretung eintragen** klicken.
2. Die Vertretung suchen (mindestens zwei Buchstaben des Namens).
3. **Von** und **Bis** wählen. Die Schnellwahl setzt das Ende auf 1, 2 oder 3 Wochen; **Bis zum Entfernen** lässt es offen.
4. **Eintragen**.

Sie können mehrere Vertretungen eintragen, z. B. für verschiedene Zeiträume oder zwei Personen gleichzeitig.

## Zeitraum ändern

**Zeitraum ändern** passt eine Vertretung an, z. B. wenn der Urlaub länger dauert. Hat die Vertretung schon begonnen, lässt sich nur noch das Ende ändern.

## Früher zurück

- **Ich bin zurück** im Statusbereich beendet alle laufenden Vertretungen sofort.
- **Beenden** beendet eine einzelne laufende Vertretung. Sie bleibt unter **Vergangene Vertretungen** sichtbar.
- **Entfernen** löscht eine geplante Vertretung, die noch nicht begonnen hat.

## Was die Vertretung im Zeitraum kann

- Sie sieht unter **Self-Service → Genehmigungen** alle Anforderungen, über die Sie entscheiden. Oben steht, wen sie vertritt.
- Sie erhält die Benachrichtigung **Genehmigung erforderlich** für neue Anforderungen.
- Sie genehmigt oder lehnt ab. In der Anforderung steht ihr Name als Entscheider.

Sie selbst können in dieser Zeit weiter entscheiden. Es genügt die Entscheidung einer Person.

::: info Gut zu wissen
- Eine Vertretung beginnt frühestens heute. Vor dem ersten und nach dem letzten Tag sieht die Vertretung nichts.
- Eigene Anforderungen der Vertretung gelten nicht automatisch als genehmigt, auch nicht im Zeitraum.
- Eine Vertretung kann nicht selbst weitere Vertretungen eintragen.
- Die Vertretung muss ein aktives Konto haben. Wird es deaktiviert, endet die Vertretung.
- Den Menüeintrag **Vertretung** sehen Genehmiger und Personen, die gerade jemanden vertreten.
:::
