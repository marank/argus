# Was ist Argus?

Argus ist die IT-Asset-Verwaltung der IT-Abteilung. Hier laufen Inventar, Anforderungen der Mitarbeitenden, die Vorbereitung und Ausgabe von Geräten und die Beschaffung zusammen.

## Was Argus abdeckt

| Bereich | Wofür |
| --- | --- |
| **Self-Service** | Mitarbeitende fordern Geräte, Software und Verbrauchsmaterial an, verfolgen den Stand und sehen ihre Geräte und Lizenzen. |
| **Genehmigungen** | Abteilungen geben Anforderungen frei, bevor die IT sie bearbeitet, wenn die Kategorie das verlangt. |
| **Anforderungen** | Die IT bestätigt, plant die Abholung, teilt Geräte zu, gibt aus und nimmt zurück. |
| **Abholterminal** | Mitarbeitende holen vorbereitete Geräte an einem Touch-PC ab und unterschreiben die Übergabe. |
| **Geräte** | Jedes Gerät mit Inventarnummer, Seriennummer, Standort, Zuordnung und vollständigem Servicebuch. |
| **Verbrauchsmaterial** | Bestand pro Lagerort mit Mindestmengen und Bewegungen. |
| **Lizenzen** | Softwarelizenzen mit Plätzen und Laufzeit, zugewiesen an Mitarbeitende oder Geräte. |
| **Meldungen** | Mitarbeitende melden Defekte, Schäden und Verluste; die IT bearbeitet sie. |
| **Beschaffung** | Aus fehlenden Geräten und Material entstehen Bestellungen; der Wareneingang legt Geräte an und teilt sie direkt zu. |
| **Stammdaten** | Hersteller, Lieferanten, Kategorien, Modelle, Standorte, Abteilungen, Mitarbeitende, Rollen und Nummernserien. |

Einzelne Module lassen sich in den [Einstellungen](./administration/settings) abschalten. Abgeschaltete Bereiche verschwinden aus der Oberfläche.

## Wer mit Argus arbeitet

| Wer | Was | Einstieg |
| --- | --- | --- |
| Mitarbeitende | Anfordern, eigene Geräte und Software einsehen, Probleme melden | [Erste Schritte für Mitarbeitende](../employees/getting-started) |
| Genehmiger | Anforderungen der eigenen Abteilung freigeben | [Genehmigungen](../approvers/approvals) |
| IT-Mitarbeitende | Anforderungen bearbeiten, Inventar pflegen, beschaffen | [Erste Schritte für die IT](./getting-started) |
| Administratoren | Stammdaten, Rollen, Einstellungen | [Erste Schritte für Administratoren](./administration/getting-started) |
| Betrieb | Installation, Updates, Sicherung | [Installation](./operations/installation) |

Welche Bereiche jemand sieht, hängt von den [Rollen](./administration/roles) ab. Ein Bereich ohne Recht ist ausgeblendet.

## Bedienung

- **Scannen:** In den IT-Ansichten funktioniert ein Barcode-Scanner überall. Eine gescannte Inventarnummer, Seriennummer, IMEI oder EAN öffnet direkt das passende Gerät oder Modell. Siehe [Scannen](./scanning).
- **Live-Updates:** Listen, Dashboards und die Zähler im Menü aktualisieren sich selbst, wenn jemand anderes etwas ändert. Solange ein Dialog offen ist, wartet die Seite damit.
- **Sprache und Darstellung:** Im Benutzermenü wählen Sie Deutsch oder Englisch und eine Darstellung (System, Hell, Dunkel und weitere).
