# Erste Schritte für die IT

Der Weg einer Anforderung, vom Eingang bis zur Rückgabe, und wo Sie im Alltag hinschauen.

## Der Arbeitsplatz

- **Dashboard**: Was zu tun ist: zu bestätigen, vorzubereiten, abholbereit, überfällig. Jede Zahl führt zur passenden Liste. Passen Sie es mit **Dashboard anpassen** an, siehe [Dashboard und Kalender](./dashboard-calendar).
- **Glocke** oben rechts: Benachrichtigungen, z. B. neue Anforderungen Ihres Teams.
- **Scanner**: Ein Scan auf einer beliebigen Seite öffnet das Gerät. Siehe [Scannen](./scanning).

## Eine Anforderung von Anfang bis Ende

1. **Eingang**: Die Anforderung erscheint unter **IT-Betrieb → Anforderungen** mit Status **Eingereicht**. Ihr Team erhält eine Benachrichtigung.
2. **Bestätigen**: Anforderung öffnen, Verfügbarkeit prüfen, **Bestätigen**. Fehlt etwas, reduzieren Sie die Menge oder bestellen es nach.
3. **Geräte zuweisen**: Geräte scannen oder **Alle automatisch zuteilen**. Die Geräte sind danach reserviert.
4. **Abholbereit melden**: Übergabeart, Termin und Abholort wählen. Der Mitarbeiter wird benachrichtigt.
5. **Übergabe**: Der Mitarbeiter unterschreibt am Abholterminal, oder Sie erfassen die Übergabe mit **Ausgeben**.
6. **Rücknahme**: Bei befristeten Anforderungen nehmen Sie die Geräte mit **Zurücknehmen** zurück, defekte mit Haken **Defekt**.

Die Details stehen unter [Anforderungen bearbeiten](./requests).

## Abkürzungen für den Alltag

| Situation | Weg |
| --- | --- |
| Jemand braucht sofort ein Gerät aus dem Regal | **Schnellzuweisung** auf der Geräteseite |
| Mehrere bestimmte Geräte für jemanden bereitstellen | **Direktausgabe** im Menü |
| Gerät ist schon beim Mitarbeiter, aber nicht erfasst | **Als ausgegeben markieren**, Geräte später erfassen |
| Gerät defekt, Ersatz nötig | **Ersetzen** auf der Geräteseite; der Gerätename geht mit |
| Akku getauscht | **Service erfassen** auf der Geräteseite |
| Neue Geräte geliefert | **Wareneingang** auf der Bestellung, Seriennummern scannen |

## Neue Geräte erfassen

- Einzeln: **Geräte → Neues Gerät**
- Viele eines Modells: **Mehrere einscannen**
- Aus einer Liste: **Importieren**, siehe [Geräte importieren](./device-import)
- Aus einer Bestellung: automatisch beim [Wareneingang](./procurement#wareneingang)

Inventarnummern und Gerätenamen vergibt Argus automatisch, wenn die Felder leer bleiben.

## Was Sie sehen dürfen

Welche Bereiche Sie sehen und ändern, legen Ihre [Rollen](./administration/roles) fest. Fehlt Ihnen ein Bereich, wenden Sie sich an einen Administrator.
