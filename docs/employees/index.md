## So läuft eine Anforderung ab

1. **Anfordern:** Unter **Neue Anforderung** wählen Sie aus, was Sie brauchen, und schicken die Anforderung ab.
2. **Genehmigung:** Muss Ihre Abteilung zustimmen, entscheidet zuerst ein Genehmiger.
3. **Vorbereitung:** Die IT bestätigt, legt die Geräte bereit und nennt Ihnen Termin und Ort.
4. **Abholen:** Sie holen die Geräte ab und unterschreiben die Übergabe.
5. **Zurückgeben:** Befristete Geräte bringen Sie bis zum Rückgabedatum zurück. Argus erinnert Sie vorher.

Bei jedem Schritt erhalten Sie eine Benachrichtigung.
