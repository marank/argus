# Abholen und zurückgeben

Sobald Ihre Geräte bereitliegen, erhalten Sie eine Benachrichtigung mit Termin und Ort. Unter **Meine Anforderungen** steht die Anforderung dann unter **Zu tun** mit **Abholen**.

Je nach Absprache bekommen Sie die Geräte auf einem von drei Wegen:

| Weg | Ablauf |
| --- | --- |
| **Am Abholterminal** | Sie prüfen die Geräte an einem Touch-PC und unterschreiben, allein oder zusammen mit der IT. |
| **Bei der IT** | Die IT übergibt die Geräte und erfasst die Übergabe. |
| **Lieferung** | Die IT bringt die Geräte an Ihren Arbeitsplatz. |

## Am Abholterminal

1. **Name antippen:** Suchen Sie Ihren Namen oder Ihre Anforderungsnummer und tippen Sie darauf.
2. **Geräte prüfen:** Sehen Sie sich die Geräte an. Stimmt etwas nicht, z. B. bei einem Kratzer oder fehlendem Zubehör, tippen Sie beim Gerät auf **Hinweis erfassen**. Weiter mit **Alles geprüft**.
3. **Wer holt ab?** Tippen Sie auf **Ich bin {Ihr Name}**.
4. **Unterschreiben:** Unterschreiben Sie im Feld und tippen Sie auf **Unterschreiben und abschließen**.

Sie erhalten danach eine Bestätigung mit allen Geräten und dem Rückgabedatum.

::: info Gut zu wissen
- Nach 2 Minuten ohne Eingabe kehrt das Terminal zum Anfang zurück. Begonnene Eingaben gehen verloren.
- Manchmal hat die IT die Geräte schon mit Ihnen geprüft. Dann beginnt das Terminal direkt mit Schritt 3.
:::

## Jemand anderes holt ab

Kann ein Kollege die Geräte für Sie abholen, wählt er am Terminal **Jemand anderes**, sucht sich nach Name oder Personalnummer und unterschreibt. Die Geräte bleiben Ihnen zugeordnet.

## Abholtermin verpasst

Die Geräte liegen weiter für Sie bereit. Holen Sie sie ab oder vereinbaren Sie mit der IT einen neuen Termin.

## Zurückgeben

Befristete Geräte bringen Sie bis zum Rückgabedatum zur IT. Das Datum steht unter **Meine Geräte**.

- Argus erinnert Sie einige Tage vorher per E-Mail.
- Ist das Datum überschritten, erscheint die Anforderung unter **Zu tun** mit **Zurückgeben**.
- Brauchen Sie die Geräte länger, sprechen Sie die IT an. Nur die IT kann die Leihfrist verlängern.

Die IT erfasst die Rückgabe. Sie erhalten danach eine Bestätigung, was zurückgenommen wurde und was noch aussteht.

Dauerhaft ausgegebene Geräte behalten Sie, bis die IT sie zurückfordert oder ersetzt.
