# Anfordern

Unter **Self-Service → Neue Anforderung** fordern Sie Geräte, Zubehör, Verbrauchsmaterial und Software bei der IT an.

## Schritt 1: Angaben

| Feld | Bedeutung |
| --- | --- |
| **Zweck** | Wofür Sie die Geräte brauchen, z. B. „Schulung“ oder „neuer Mitarbeiter“. Pflichtfeld. |
| **Dauer** | **Befristet**: für einen Zeitraum ausleihen. **Dauerhaft**: als Arbeitsmittel behalten. |
| **Zeitraum** | Bei befristeten Anforderungen: von wann bis wann. Vorgeschlagen wird die Standard-Ausleihdauer. |
| **Benötigt ab** | Bei dauerhaften Anforderungen: ab wann. |
| **Abholung gewünscht am** | Ihr Wunschtermin für die Abholung. Den genauen Termin legt die IT fest. |

Der Wunschtermin folgt automatisch dem ersten Tag des Zeitraums, bis Sie ihn ändern. Er darf früher liegen, aber nicht in der Vergangenheit und nicht nach dem Tag, ab dem Sie die Geräte brauchen.

## Schritt 2: Auswahl

Wählen Sie eine Kategorie oder suchen Sie direkt, z. B. nach „Headset“. Je nach Kategorie haben Sie diese Möglichkeiten:

- **Beliebiges Modell**, z. B. „Headset · beliebiges Modell“: Die IT wählt ein passendes Gerät aus.
- **Bestimmtes Modell**: Sie legen das Modell fest.
- **Etwas anderes aus {Kategorie}**: Sie beschreiben, was Sie brauchen. Die IT prüft den Wunsch.

Welche Möglichkeiten eine Kategorie bietet, legt die IT fest. Bei manchen Kategorien wählt immer die IT das Modell, bei anderen (z. B. Toner) müssen Sie ein bestimmtes Modell wählen.

Mit **+** und **−** legen Sie die Menge fest. Zu jedem Artikel können Sie einen **Hinweis** hinterlegen.

### Passend zu Ihren Geräten

Diese Kachel zeigt Verbrauchsmaterial und Zubehör, das zu Ihren eigenen Geräten passt, z. B. die richtige Tintenpatrone für Ihren Drucker.

### Zubehör

Unter einem Modell erscheint passendes Zubehör, z. B. eine Dockingstation zum Notebook.

### Nicht im Katalog?

Findet die Suche nichts, beschreiben Sie den Bedarf unter **Gesuchter Artikel nicht im Katalog?**. Solche Positionen erscheinen im Warenkorb als **Sonderwunsch · IT prüft**.

### Software

Software fordern Sie wie Geräte an, in den Software-Kategorien. Die IT weist Ihnen danach eine Lizenz zu. Sie erscheint unter [Meine Software](./overview#meine-software).

## Schritt 3: Prüfen und absenden

Im **Warenkorb** sehen Sie alle Positionen. Unter **Mitteilung** können Sie der IT noch etwas mitteilen. Mit **Anforderung absenden** geht die Anforderung ab.

Danach sehen Sie die Anforderung mit ihrer Nummer. Wie es weitergeht:

- **Mit Genehmigung:** Enthält die Anforderung etwas, das Ihre Abteilung genehmigen muss, geht sie zuerst an die Genehmiger. Status: **In Genehmigung**.
- **Ohne Genehmigung:** Die Anforderung geht direkt an die IT. Status: **Eingereicht**.

Sie werden per E-Mail und in Argus benachrichtigt, sobald sich etwas tut.

::: info Gut zu wissen
- Eine einzige genehmigungspflichtige Position genügt, und die ganze Anforderung braucht eine Genehmigung.
- Sind Sie selbst Genehmiger Ihrer Abteilung, gilt Ihre eigene Anforderung als genehmigt.
- Sind Sie von Genehmigungen befreit, geht jede Anforderung direkt an die IT.
- Hat die IT eine maximale Ausleihdauer festgelegt, lässt sich kein längerer Zeitraum wählen.
- Wie viele Geräte verfügbar sind, sehen nur IT-Mitarbeitende. Fordern Sie an, was Sie brauchen; die IT meldet sich, falls etwas nicht verfügbar ist.
:::

## Erneut anfordern

Bei abgeschlossenen, abgelehnten oder stornierten Anforderungen gibt es **Erneut anfordern**. Das Formular ist dann mit den bisherigen Angaben gefüllt; Daten in der Vergangenheit werden auf heute gesetzt. Beim Absenden entsteht eine neue Anforderung, die auf die alte verweist.

## Eine Anforderung abbrechen

Solange Sie noch im Formular sind, verwirft **Anforderung abbrechen** alle Angaben. Eine bereits abgeschickte Anforderung können Sie stornieren, siehe [Meine Anforderungen](./overview#stornieren).
